## 알려진 제한
- 지도 역명과 서울 API 역명이 다른 역(부역명 포함)은 별칭 표로 재시도하며, 일부 누락될 수 있음.
- 위젯 자동 갱신은 약 15분 간격(Android JobScheduler 최소 주기). 즉시 갱신은 ⟳.
- 위젯 위치 갱신 ON 상태에서 앱이 닫혀 있으면 위치 권한 ‘항상 허용’이 필요.
